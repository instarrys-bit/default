## Source of truth

Executable workflows, scripts, registries, manifests, tests, and the protected user configuration define actual behavior. Generated reports describe individual runs; they are not policy specifications. If documentation conflicts with implementation, investigate the discrepancy instead of silently changing runtime behavior.
